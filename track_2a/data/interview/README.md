# Public interview resources

Copied from the [FHGR Hackapertus datasets](https://github.com/fhgr/Hackapertus/tree/main/datasets): question bank, fictional apprenticeship postings, FHGR criteria and feedback guidelines. The organisers describe the source material in `datasets/README.md`. French/Italian question translations and synthetic content require review.

These files are runtime resources. Candidate simulator profiles, annotations, scenario success criteria and adaptive hooks are not shipped to the coach. Public posting facts provide context for answering candidate questions. They do not guarantee grounded answers: development review found invented details and unanswered questions. The default browser session chooses a fictional posting corresponding to the selected occupational scenario.

Source SHA-256 values are recorded in `manifest.json`. Update resources deliberately; do not modify the organisers' originals.

Bundled resources retain upstream attribution and usage conditions. Their inclusion grants no additional rights beyond the organiser-provided terms. The source files are unchanged; `manifest.json` records their SHA-256 values.
